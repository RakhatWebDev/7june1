# Цели проекта FORMA

Владелец: Рахат (183 см, 88 кг, цель — эстетичное тело: снизить жир до ~82 кг, сохранить/набрать мышцы).

## Главная цель (G0)

Одно приложение, открываемое с телефона в зале, которое за 3 секунды показывает «что делать сейчас»
и позволяет записывать результат одним-двумя тапами. Без аккаунтов, без интернета (после первой загрузки).

## Цели по направлениям

| # | Цель | Критерий готовности (Definition of Done) |
|---|------|------------------------------------------|
| G1 | **Тренировка в зале** по программе (David Laid DUP 6 дней) | Открыл «Зал» → вижу день по расписанию → «Начать» → для каждого упражнения вижу анимацию/кадры + инструкцию + план (подходы×повторы) → ввожу вес/повторы, отмечаю подход → таймер отдыха запускается автоматически → «Завершить» сохраняет сессию. Предыдущие результаты упражнения подставляются как подсказка. |
| G2 | **Библиотека упражнений** | Поиск по названию, фильтры по мышце/оборудованию/категории. Карточка: анимация, инструкция, мышцы, история моих подходов, личный рекорд. |
| G3 | **Кардио и активности** | Запись бега/вело/плавания/скакалки/ходьбы/HIIT: длительность, дистанция/счёт, пульс, заметка. Недельная сводка (минуты, км). Комплексы растяжки с картинками из библиотеки (category = stretching), таймер на каждое упражнение. |
| G4 | **Питание** | Профиль → расчёт BMR (Mifflin–St Jeor), TDEE, целевые ккал и макросы по цели (сушка −15–20 %, поддержка, набор +10 %). Дневник дня по приёмам пищи, библиотека продуктов (на 100 г) + быстрый ввод. Вода со стаканами. Прогресс-бары ккал/Б/Ж/У. |
| G5 | **Сон** | Запись отбоя/подъёма (длительность считается), качество 1–5. График 14 дней, среднее за 7 дней, сравнение с целью 8 ч. |
| G6 | **Прогресс** | Вес (график + скользящее среднее 7 дней), замеры тела, объём нагрузки по неделям, список личных рекордов (max вес × повторы, расчётный 1RM по Epley), серия дней активности (streak). |
| G7 | **Сегодня** (дашборд) | Один экран: тренировка дня (кнопка «Начать»/«Продолжить»), сводка питания и воды, сон прошлой ночи, вес, активности за сегодня. |
| G9 | **Календарь занятий (OneFit)** | Импорт .ics или подписка по URL → ближайшие занятия на дашборде и на `/calendar`; событие «зал» ведёт к старту тренировки, «бассейн» — к записи активности. Повторный импорт не создаёт дублей. |
| G8 | **Данные под контролем** | Экспорт всего в JSON-файл и импорт обратно. Профиль редактируется. PWA устанавливается на телефон, работает offline. |

## Нефункциональные критерии (применяются ко всем задачам)

- `npm run check` зелёный: typecheck, lint, тесты, production build.
- Mobile-first: вся функциональность доступна при ширине 360 px без горизонтального скролла; крупные тап-зоны (≥ 40 px).
- Интерфейс на русском. Названия упражнений из библиотеки — на английском (так в базе), с русским названием из программы, где есть.
- Каждое feature-направление имеет ≥ 1 unit-тест бизнес-логики (расчёты, агрегаты) и ≥ 1 тест рендера страницы.
- Никаких внешних сервисов, кроме картинок упражнений с raw.githubusercontent.com (кэшируются service worker'ом).
- Пустые состояния понятны и подсказывают первое действие.

## Вне скоупа MVP (следующие итерации)

ИИ-рекомендации, собственные видео, конструктор программ с перетаскиванием (в MVP — только редактирование JSON-полей).
