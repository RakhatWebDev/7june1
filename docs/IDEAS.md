## Зал
- ⭐⭐⭐ **Калькулятор блинов**: ввёл 102,5 кг → показывает, какие блины повесить на гриф 20 кг с каждой стороны.
- ⭐⭐⭐ **Разминочные подходы** для основного движения: 40 % × 8, 60 % × 5, 80 % × 3 от рабочего веса.
- ⭐⭐⭐ **Авто-прогрессия**: если все рабочие подходы выполнены с RPE ≤ 8 — подсказка «+2,5 кг в следующий раз».
- ⭐⭐ **Разгрузочная неделя**: напоминание каждую 5-ю неделю, автоматическое −35 % объёма.
- ⭐⭐ Конструктор программ (drag-and-drop дней/упражнений), копирование встроенной программы под себя.
- ⭐ Суперсеты и дроп-сеты; заметки по технике к упражнению с фото.

## Тело и восстановление
- ⭐⭐⭐ **% жира по US Navy** из замеров (шея, талия, рост) — без калипера, прямо из `measurements`.
- ⭐⭐⭐ **Readiness-индекс** на «Сегодня»: сон (длительность × качество) + самочувствие после прошлой тренировки → «тяжело / норма / легко».
- ⭐⭐ Фото прогресса (хранить в IndexedDB как Blob, сравнение «до/после» слайдером).
- ⭐⭐ Еженедельный отчёт (воскресенье): вес, объём, кардио-минуты, средний сон, соблюдение ккал.

## Питание
- ⭐⭐⭐ **Шаблоны дня** («мой обычный завтрак») — добавление одним тапом.
- ⭐⭐ Сканер штрихкодов через Open Food Facts (бесплатное API, CORS открыт).
- ⭐⭐ Адаптивные калории: если за 2 недели вес не меняется в сторону цели — предложить −100 ккал.

## Календарь / OneFit
- ⭐⭐⭐ Google Calendar API через OAuth (client id в настройках) — автосинк без ручного .ics.
- ⭐⭐ Запись завершённой тренировки обратно в календарь (.ics-файл «добавить в календарь»).
- ⭐ Напоминание за 60 минут до занятия (Web Push требует сервер — пока локальные уведомления при открытом приложении).

## Платформа
- ⭐⭐⭐ Экспорт в CSV по таблицам (для Excel/Sheets).
- ⭐⭐ Синхронизация между устройствами через файл в Google Drive / iCloud (экспорт-импорт автоматизированный).
- ⭐ Светлая тема; английская локализация.
