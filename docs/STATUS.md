## Как это делалось

Архитектор (одна сессия) держал ядро (`src/db`, `src/components`, `src/app`, документы), 13 агентов Opus
работали параллельно каждый в своей папке `src/features/<feature>/` по заданиям из `docs/TASKS.md`
с критериями приёмки; приёмка — тесты + скриншоты 360/390 px + сценарии в Playwright; доработки — обратно агенту.
